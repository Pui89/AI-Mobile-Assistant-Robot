# Initial Safety Case

**PROPOSED — not a certification or completed hazard analysis.**

Intended use: summarize building-condition observations to help a responsible person decide what needs verification.

Out of scope: replacing certified fire/smoke/CO/electrical protection; declaring a building safe or unsafe; diagnosing causes from one sensor; operating breakers, valves, lifts, doors, alarms or evacuation controls; decisions about tenants or individuals.

| Hazard | Control |
|---|---|
| Missed emergency | Certified alarms and protective devices remain primary; software cannot delay response |
| False alarm | Show evidence, uncertainty, thresholds and human verification |
| Missing/stale data | Explicit data-gap and sensor-health status; never imply normality |
| Bad calibration/mounting | Exclude or downgrade data; record calibration provenance |
| Incorrect causal inference | Use possible/consistent-with language and alternatives |
| Privacy intrusion | Minimize data, control access and retention |
| Unsafe actuation | No actuator interface in initial product |
| Cyber compromise | Dependency review, least privilege, secret scanning and threat modelling |

Never wait for additional AI analysis before acting on a certified alarm or obvious emergency. No safety-critical action is automated.
