# Security Policy

## Scope

HOMEGUARD AI is an early-stage, software-first building-condition intelligence demonstrator. It is not a certified fire, intrusion, structural, electrical or life-safety system.

## Reporting a vulnerability

Please do not publish exploit details, credentials, private building data or personal information in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security → Advisories → Report a vulnerability** flow. Otherwise, contact the repository maintainer privately through an established channel before public disclosure. Do not include sensitive operational details in public discussions.

Please include the affected version or commit, a concise impact description, reproducible steps where safe, and any suggested mitigation.

## Security response

Reports will be triaged on a best-effort basis. No response-time or remediation-time guarantee is made while this project is maintained on a limited-resource basis.

## Current security limitations

- Automated scans are safeguards, not proof that the software is secure.
- No production deployment or independent penetration test is claimed.
- No real building network, sensor gateway or actuator is connected by the initial demonstrator.
- Never use this software as the only protection against fire, intrusion or another emergency.
